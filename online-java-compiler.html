Basic Example: Hello World

In Java, all code must reside inside a class. Here is the standard way to print text to the console:

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

Reading Input with Scanner

The java.util.Scanner class is the easiest way to read user input. Add your inputs to the Standard Input tab in the IDE before running.

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.print("Enter your name: ");
        String name = scanner.nextLine();
        
        System.out.println("Welcome to Java, " + name + "!");
        scanner.close();
    }
}

Object-Oriented Programming (OOP)

Java is an object-oriented language. You can define classes, objects, and methods directly in the web editor:

class Rectangle {
    int width;
    int height;
    
    Rectangle(int w, int h) {
        width = w;
        height = h;
    }
    
    int getArea() {
        return width * height;
    }
}

public class Main {
    public static void main(String[] args) {
        Rectangle rect = new Rectangle(5, 10);
        System.out.println("Area: " + rect.getArea());
    }
}
