Functions and Loops

def fibonacci(n):
    a, b = 0, 1
    result = []
    for _ in range(n):
        result.append(a)
        a, b = b, a + b
    return result

print("First 10 Fibonacci numbers:")
print(fibonacci(10))

Frequently Asked Questions

Which Python version is supported?

The compiler environment simulates modern Python 3 (Python 3.10+) execution behavior.

Can I import standard libraries?

Yes, most built-in standard libraries such as math, random, datetime, and json are supported.

Are external packages like NumPy or Pandas supported?

Currently, the compiler focuses on core Python language features and the standard library. Heavy third-party data science packages that require C-extensions are not supported in this lightweight web environment.
