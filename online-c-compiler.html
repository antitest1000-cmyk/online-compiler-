Handling Standard Input (scanf)

Our IDE fully supports standard input. You can read user input using functions like scanf or fgets. Simply enter your input in the "Standard Input" tab before running the program.

#include <stdio.h>

int main() {
    int age;
    printf("Enter your age: ");
    scanf("%d", &age);
    printf("You are %d years old.\n", age);
    return 0;
}

Using Arrays and Loops

#include <stdio.h>

int main() {
    int numbers[] = {10, 20, 30, 40, 50};
    int sum = 0;
    
    for (int i = 0; i < 5; i++) {
        sum += numbers[i];
    }
    
    printf("Total sum: %d\n", sum);
    return 0;
}

Frequently Asked Questions

Which C standard is supported?

The compiler environment is compatible with modern C standards including C99 and C11, supporting most standard GCC/Clang syntax.

Are external libraries supported?

Standard libraries (like <math.h>, <stdlib.h>, <string.h>) are fully supported. Third-party libraries that require manual linking (like OpenGL or custom Makefiles) are not supported in the web environment.

Is my code saved?

Yes, your code is automatically saved in your browser's local storage. When you return to the site, your code will be exactly as you left it.
