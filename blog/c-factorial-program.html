C Program to Find Factorial of a Number

4 min read · Exam Preparation · C Programming

The factorial of a non-negative integer n is the product of all positive integers less than or equal to n. It is denoted by n!. For example, the factorial of 5 is 5! = 5 × 4 × 3 × 2 × 1 = 120. The factorial of 0 is 1.

Finding the factorial of a number is one of the most frequently asked programs in university practical exams and coding interviews. Below are the two most common ways to solve this in C: using a for loop and using recursion.

Method 1: Factorial using a for loop

This is the standard iterative approach. We use a loop that multiplies the numbers from 1 up to n.

#include <stdio.h>

int main() {
    int n, i;
    unsigned long long fact = 1;
    
    printf("Enter an integer: ");
    scanf("%d", &n);
    
    // Error condition for negative numbers
    if (n < 0) {
        printf("Error: Factorial of a negative number doesn't exist.\n");
    } else {
        for (i = 1; i <= n; ++i) {
            fact *= i;
        }
        printf("Factorial of %d = %llu\n", n, fact);
    }
    
    return 0;
}

Method 2: Factorial using Recursion

A recursive function is a function that calls itself. We can define factorial recursively as: n! = n × (n-1)!.

#include <stdio.h>

unsigned long long multiplyNumbers(int n);

int main() {
    int n;
    printf("Enter a positive integer: ");
    scanf("%d", &n);
    
    if (n >= 0)
        printf("Factorial of %d = %llu\n", n, multiplyNumbers(n));
    else
        printf("Factorial of negative number doesn't exist.\n");
        
    return 0;
}

unsigned long long multiplyNumbers(int n) {
    if (n >= 1)
        return n * multiplyNumbers(n - 1);
    else
        return 1;
}

Important Note: Data Types

Notice that we used unsigned long long instead of int for the fact variable. Factorials grow exponentially fast. The factorial of 13 is already too large to fit in a standard 32-bit signed integer. Using an unsigned 64-bit integer allows us to calculate factorials up to 20!.

Frequently Asked Questions

What is the factorial of 0?

By mathematical convention, 0! = 1. Both programs above will correctly output 1 if you input 0.

Why does the output become 0 or negative for large numbers?

This is called integer overflow. If you enter a number like 100, the result exceeds the maximum limit of the unsigned long long data type, leading to garbage values. To handle huge factorials, you need to use arrays to store the digits manually.
