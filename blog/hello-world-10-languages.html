Hello World in 10 Languages

8 min read · Multi-Language · Beginner

"Hello, World!" is traditionally the first program written by people learning to code. It is a simple program that outputs exactly that phrase to the screen, verifying that the language environment is properly set up.

1. C

#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}

2. Python

print("Hello, World!")

3. Java

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

4. C++

#include <iostream>

int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}

5. JavaScript (Node.js)

console.log("Hello, World!");
