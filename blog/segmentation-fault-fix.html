Segmentation Fault (Core Dumped) — Meaning and Fix

6 min read · C / C++

A Segmentation Fault (often shortened to segfault) occurs when a program attempts to access a memory location that it is not allowed to access.

Common Cause 1: Missing & in scanf

// WRONG
int age;
scanf("%d", age); // Segfault!

// RIGHT
int age;
scanf("%d", &age);

Common Cause 2: Dereferencing a NULL Pointer

// WRONG
int *p = NULL;
*p = 10; // Segfault!
