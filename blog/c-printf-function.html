printf() in C

5 min read · Standard Library: <stdio.h>

The printf() function is used to print formatted output to the standard output stream (usually the console/terminal). It is the most commonly used output function in C programming.

Syntax

int printf(const char *format, ...);

Parameters:

  • format: A C string that contains the text to be written. It can optionally contain embedded format specifiers that are replaced by the values specified in subsequent arguments.
  • ...: Additional arguments matching the format specifiers.

Return Value: Returns the total number of characters printed successfully. If an error occurs, it returns a negative number.

Basic Example

#include <stdio.h>

int main() {
    int age = 21;
    float gpa = 3.8;
    char grade = 'A';
    
    printf("Age: %d\n", age);
    printf("GPA: %.2f\n", gpa);
    printf("Grade: %c\n", grade);
    
    return 0;
}

Common Format Specifiers

Specifier Data Type Description
%d or %i int Signed decimal integer
%f float / double Decimal floating point
%c char Single character
%s char array / pointer String of characters
%p pointer Memory address
%x unsigned int Hexadecimal integer (lowercase)

Formatting Numbers (Width and Precision)

You can control exactly how numbers are printed using width and precision modifiers:

#include <stdio.h>

int main() {
    float pi = 3.14159265;
    
    // Default printing
    printf("Default: %f\n", pi);
    
    // Print with exactly 2 decimal places
    printf("Two decimals: %.2f\n", pi);
    
    // Right-align within 10 characters
    printf("Right aligned: %10.2f\n", pi);
    
    // Pad with leading zeros
    printf("Zero padded: %010.2f\n", pi);
    
    return 0;
}

Frequently Asked Questions

Why do I need to include <stdio.h>?

The printf() function is part of the Standard Input/Output library. If you don't include this header, the compiler won't know how to execute the function, leading to an "implicit declaration" warning or error.

How do I print a percent sign (%)?

Because % is a special character used for format specifiers, you must escape it by typing it twice: printf("Score: 100%%\n");
