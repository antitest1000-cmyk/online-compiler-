IndentationError: unexpected indent

4 min read · Python

Python relies on leading whitespace (spaces and tabs) to define code blocks. If you add spaces where they don't belong, or mix tabs and spaces, Python throws an IndentationError.

The Fix

Ensure that all lines in the same block have the exact same number of leading spaces. Do not mix tabs and spaces.

# WRONG
def say_hello():
    print("Hello")
     print("World") # Notice the extra space here!

# RIGHT
def say_hello():
    print("Hello")
    print("World")
